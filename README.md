# Quiz en images — Android (Kotlin + XML)

Application Android éducative avec cinq questions illustrées sur les formes géométriques.

## Fonctionnalités
- Une seule activité : `MainActivity`.
- Interface déclarée dans `activity_main.xml` (pas de Jetpack Compose).
- Cinq questions statiques en Kotlin et cinq images locales.
- Trois choix par question, correction immédiate et blocage après réponse.
- Score et progression indépendants.
- Résultat final dans la même activité et bouton **Rejouer**.
- Interface défilante pour les petits écrans.
